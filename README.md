# Calculadora de IMC

Projeto simples em React para calcular o Índice de Massa Corporal (IMC) de um usuário, com exibição do resultado, classificação e histórico de medições.

## Descrição

A aplicação permite:
- inserir peso e altura;
- calcular o IMC automaticamente;
- visualizar a classificação do resultado;
- manter um histórico das medições realizadas pelo usuário no navegador.

## Como rodar

1. Acesse a pasta do projeto:
   ```bash
   cd .../Calculadora-imc-guif
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o projeto:
   ```bash
   npm run dev
   ```

4. Abra no navegador a URL exibida no terminal, normalmente:
   ```bash
   http://localhost:5173/
   ```

## Build para produção

```bash
npm run build
```
